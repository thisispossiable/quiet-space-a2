# Quiet Space: Wellbeing Support Prototype

## Project Status

Quiet Space is a runnable browser prototype for low-risk emotional self-check-in and reflective support. A user can select a feeling, set a stress level, enter a short message, request a support action, and start a three-minute timer.

- **Implemented:** responsive interface, emotion choices, stress slider, chat input, rule engine, safety notice, browser-local storage, and session clearing.
- **Simulated:** all suggestions are generated by explicit rules. The prototype does not use a generative AI model or claim to diagnose emotion or mental illness.
- **Not yet implemented:** participant evaluation, accounts or persistent storage, and validated professional referral data.
- **Placeholder behaviour:** risk words trigger a fixed support notice. This is not a clinical risk assessment.

## Technology Stack

- HTML, CSS and vanilla JavaScript.
- Browser `localStorage` for the current quick check-in.
- No framework or server-side dependency.
- No external AI model or API is called.

## Run or Inspect

Open `index.html` directly, or run the local server from the project directory:

```powershell
python -m http.server 8000
```

Visit `http://localhost:8000`.

Use **Clear this session** to remove the saved check-in. Browser settings can also clear site data.

## Development Record

- The scope was limited to reflective, non-clinical support to avoid false diagnosis and harmful overpromises.
- Fixed choices and a stress scale were selected because they make user input predictable and help users make a first small decision.
- A transparent rule engine was introduced instead of an unconstrained language model. This makes the prototype's behaviour easier to demonstrate and inspect.
- Crisis phrases trigger a fixed emergency and trusted-person notice rather than ordinary wellbeing advice.
- The prototype was checked for page loading, the desktop/mobile layout, completed interactions, record clearing, and absence of network submission.
- Further work should add usability testing, more careful safety wording and tested referral information.
